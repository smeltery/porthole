03 / Good to know

A few practical
details.

Local tools, explicit permissions, and documentation for the parts that matter.

What does Porthole read?

Local Slipway logs, captured output and the first prompt from supported agent transcripts. It uses SSH for the live screen and checks GitHub for updates.

Does it control the VM?

No. Slipway drives the guest. Porthole only observes it, so opening the monitor cannot launch a VM or send keyboard input.

Are release builds notarized?

CI builds are ad-hoc signed and are not notarized. Read the release documentation before opening a download, or build from source with Xcode 26+.
